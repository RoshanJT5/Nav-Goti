## Screenshot Best Practices

### Design Guidelines
1. **Remove Status Bar** - Hide device status bar for cleaner look
2. **Use Device Frames** - Consider adding device frames for context (optional)
3. **Consistent Lighting** - Ensure all screenshots have similar brightness
4. **High Quality** - Use highest resolution possible
5. **Text Overlays** - Add captions/annotations if needed (keep minimal)

### Content Guidelines
1. **No Personal Info** - Don't show real usernames or emails
2. **Family Friendly** - All content must be appropriate for 4+ rating
3. **Accurate Representation** - Screenshots must reflect actual gameplay
4. **Localization** - Create separate screenshots for each supported language
5. **Seasonal Updates** - Update screenshots with major app updates

### Technical Requirements
- **Format:** PNG or JPEG
- **Color Space:** sRGB or P3
- **No Alpha Channels** - Fully opaque images only
- **File Size:** Under 5MB per screenshot
- **Orientation:** Portrait for phones, landscape for tablets (optional)
